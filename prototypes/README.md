# UI prototypes

Clickable layout studies for the site, built on sample recipes in the app's
Catppuccin Mocha palette. Open either file in a browser; nothing here is wired
to the server.

- `meal-layouts.html` — five alternative layouts, with a desktop/phone toggle.
- `meal-planner-combo.html` — the chosen direction: a Plan page (week board)
  and a Recipes page (list + reader), shown at desktop and phone width on shared
  data. Meals can be dragged between days (or onto each other to swap) with a
  mouse or touch.
